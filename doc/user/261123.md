  - 다시 누르거나(`작게 보기`) 키보드 `Esc`를 누르면 원래 크기로 돌아옵니다.

  - 휴대폰 너비에서는 글자 없이 아이콘만 보입니다.

- (추가) 크게 보기 화면에 오른쪽 **검색 결과 목록**도 함께 보이게 했습니다. 넓은 화면은 지도 | 목록 나란히, 좁은 화면은 지도 위 · 목록 아래로 배치됩니다.
- (추가) 크게 보기 중에 **목록의 모임을 누르면** 상세 페이지로 넘어가지 않고 지도가 그 모임 위치로 이동·확대되고 말풍선이 열립니다. 상세 페이지는 말풍선의 '모임 자세히 보기'로 갈 수 있고, 평소 크기에서는 예전처럼 바로 상세로 이동합니다. 지도 핀을 누르면 목록에서도 그 모임이 노랗게 표시됩니다.

## 사용한 기술
- CSS `position: fixed` 로 지도 패널을 화면 전체에 띄움.
- 카카오 지도는 크기가 바뀌면 `map.relayout()` 을 호출해야 타일이 다시 그려지므로, 크기를 바꾼 뒤 이 함수를 부르고 중심 좌표를 다시 맞춤.

## 확인 방법

2. http://localhost:8888 → "동네 지도" 오른쪽 위 `크게 보기` 클릭 → 화면 전체 지도 확인 → `Esc` 로 닫기.

# 모임 수명주기: 끝나는 시간과 상태

## 한 일
- 모임을 만들 때 **진행 시간**(30분, 1시간, 1시간 30분, 2시간, 3·4·6·8·12시간)을 고릅니다. 끝나는 시간은 서버가 "시작 + 진행 시간"으로 계산해서 저장합니다. 선택 칸 아래에 "16:30에 끝나요"처럼 끝나는 시간이 보입니다.
- 모임 상태를 네 가지로 나눴습니다. 상태는 저장하지 않고 볼 때마다 시간과 인원으로 계산합니다.

| 상태 | 언제 |
|---|---|
| 모집 중 | 시작 전, 자리 있음 |
| 모집 마감 | 시작 전, 정원 참 |
| 진행 중 | 시작 ~ 끝나는 시간 |
| 종료 | 끝나는 시간이 지남 |

- 바뀐 규칙

| 화면 | 전 | 지금 |
|---|---|---|
| 홈 지도·목록 | 시작하면 사라짐 | **끝날 때까지 보임**. 진행 중이면 "진행 중" 배지와 "16:00까지" 표시 |
| 참여하기 | 시작하면 막힘 | **끝나기 전까지 가능** (늦게 합류). 끝나면 "끝난 모임" |
| 참여 취소·모임 수정 | 시작 전만 | 그대로 시작 전만 |
| 모임 상세 | 시작 시간만 | "11월 24일 (화) 14:00 ~ 16:00 (2시간)" + 상태 배지 |
| 내 모임 | 시작하면 "지난 모임" | 진행 중인 모임은 위에 남고, 끝난 모임만 "끝난 모임 N개"로 접힘. 모든 줄에 배지 |

- 기존 모임은 끝나는 시간을 모르므로 **시작 + 2시간**으로 채웁니다.

## 사용한 기술과 이유
- Flyway `V2__add_gathering_end_at.sql`: 컬럼 추가 → 기존 행 채우기 → NOT NULL. 앱을 다시 켜면 자동으로 한 번 실행됩니다.
- 끝나는 시간을 직접 받지 않고 진행 시간을 받는 이유: 끝이 시작보다 앞서는 잘못된 입력이 생길 수 없습니다.
- 상태를 DB에 저장하지 않는 이유: 시간이 지나면 저절로 바뀌므로, 저장하면 금방 틀린 값이 됩니다.
